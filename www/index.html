关于照片水印

本应用完全离线运行：照片、EXIF 解析、水印渲染全部在本机完成，不会上传任何照片。

仅在解析地址时，会把该照片的经纬度（不含照片本身）发送给你所选的地图服务商以换取文字地址。

API Key 只保存在本机，不会上传到第三方。
